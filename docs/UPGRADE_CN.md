# ExtremaRank v0.2：扩大实际使用范围

v0.2 将使用范围从固定配对差值，扩展为三种工作流。原来的条件二族极值定理
和配对审计仍然保留；新增功能的用途和保证单独说明。

| 工作流 | 可以处理的问题 | 结论范围 |
|---|---|---|
| 配对审计 | 同供体干预前后、处理/对照、同患者组织配对 | 普通配对 t 的精确单特征极值，以及共同删除的 Top-K 审计 |
| 独立两组 Welch 审计 | 不同供体的病例/对照、不同处理组等数值特征比较 | 精确 Welch 排名比较与有预算的完整枚举；预算不足返回未解决 |
| 外部排名表比较 | limma、DESeq2、协变量模型或自定义方法已经重拟合的结果表 | 只评价提供的情景，不保证其他未检查的删除组合；已实测 limma 接口 |

独立两组模式要求每个生物供体只有一行、各组至少保留两例；这些是计算条件，
不意味着两例足以支撑可靠科学推断。相同供体的重复测量不能当作独立样本。
外部接口不内置 DESeq2、混合模型或协变量拟合，用户仍需在适当的分析流程中
完成重拟合，再导入排名分数。

## 使用门槛降低了什么

- 支持常见的“特征×样本”矩阵，也支持样本在行的矩阵；读取 CSV、TSV 和 gzip。
- 用 `sample_id` 严格连接元数据，显式指定目标组和参考组，不靠字母顺序猜方向。
- 配对元数据检查完整配对、重复供体/组别；独立设计检查重复供体。
- 可以显式选择不转换、log2、CPM+log2；缺失特征和不完整配对默认报错，
  只有显式选择排除才执行，并保存排除记录。无自动填补和逐基因更换供体集。
- 每个 `study` 输出离线 HTML、样本影响表和全部特征的逐样本删除诊断，
  直接显示哪些候选进入/退出、排名范围和方向变化。

排名范围来自基线及可行的逐样本删除，选择比例是已检查情景中的频率，
不是置信概率，也不是删除多个样本后的排名界限。元数据中的批次、年龄、性别
可以保留作为上下文，但原生模式不会拟合这些协变量。

## 实际执行的验证

新增数据为 Bioconductor `multtest` 的 Golub 白血病微阵列训练集：
27 例 ALL、11 例 AML、3,051 个已由数据提供者筛选的特征。
目标为 AML−ALL，使用提供者已经处理的矩阵，冻结所有预处理。
这不是新的疾病预测实验，也不把处理后均值差解释为原始表达的倍数变化。

冻结参数：Top-20，删除预算 1 和 2，向上、向下、绝对值三个排名方向。
六个 Welch 审计都找到一个真实共同删除的反例；逐样本删除中，
改变名单的情景分别为 **27/38、34/38、38/38**。
这说明它能定位候选列表对样本的依赖，不代表这些候选是错误的。

独立有理数实现复核了基线及全部逐样本删除的三个方向，共 **117 次完整
3,051 特征排名**，全部一致。所有返回的共同删除见证也经过核对。
小问题的独立枚举完成 **2,000 个问题、91,227 次排名、6,000 次完整审计状态
检查**，没有不一致。结果保存在 `results/upgrade_real.json` 和
`results/independent_welch_check.json`。

外部方法验证使用 limma 3.68.5：每次删除后重新拟合 `~group` 并重新计算
经验贝叶斯方差收缩。38 个删除情景在三个方向分别有 **28、30、33 个**
改变 Top-20；基线和情景共 **117 个 Top-20 集合**与 R 端输出一致。
输出标记为 `OBSERVED_CHANGED`，不沿用原生审计的 `CERTIFIED` 标签。

单次本机测试中，Welch 工作流包含 38 个逐样本诊断和报告准备，耗时为秒级
（具体数值记录在结果 JSON，不包含最终输出写入）。这些例子很快找到了反例，不代表复杂稳定数据也会
同样快；Welch 枚举和原来的共同删除搜索都可能因预算限制而未解决。

## 直接复现

```bash
python -m pip install .
extremarank study data/prepared/Golub/matrix.csv.gz \
  --metadata data/prepared/Golub/metadata.tsv \
  --target AML --reference ALL --design welch \
  --budget 2 --top-k 20 --output golub-audit
```

打开 `golub-audit/report.html`。更多准备选项、外部表格式和 limma 示例见
[完整工作流说明](STUDY.md)。打包分发的部分大表为 `.gz`；重复执行命令会
生成普通 CSV/TSV，保留所有数据内容。

## 目前可以怎样定位

它现在是配对、独立两组以及外部模型候选列表的**样本删除稳健性检查工具**。
实证范围增加了非配对微阵列和 limma 重拟合；蛋白组、代谢组等只要符合
数值和研究设计合同，可以接入，但尚未进行真实跨组学验证。
对外部复杂模型只有已提供情景的比较；原生模式没有协变量调整或 FDR 控制。
上游原始数据身份/基因型复核未执行，公开处理矩阵的身份依赖来源记录。
没有宣称提高标志物验证率、临床效果、全球数学优先权或 GitHub 星标保证。
